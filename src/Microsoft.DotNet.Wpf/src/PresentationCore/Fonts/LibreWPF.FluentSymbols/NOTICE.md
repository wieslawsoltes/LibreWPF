# LibreWPF Fluent Symbols notices

`LibreWPF.FluentSymbols.ttf` is a modified compatibility font generated by the
LibreWPF project. It is not Microsoft's Segoe Fluent Icons or Segoe MDL2 Assets
font, and contains no outlines copied from either proprietary Segoe font.

The font starts from Uno Fluent Icons by Uno Platform/nventive, distributed
under Apache License 2.0. LibreWPF changes its family metadata and adds legacy
code-point mappings and outlines selected from Microsoft Fluent System Icons,
distributed under the MIT License. The legacy code-point catalog is derived
from Microsoft's MIT-licensed WPF Gallery sample. Exact source revisions,
download hashes, generated-file hashes, and license file names are recorded in
`SOURCE-MANIFEST.json`.

The compatibility mappings are semantic substitutes. They preserve the legacy
private-use code-point contract across portable LibreWPF platforms but do not
claim pixel-identical Segoe artwork.
